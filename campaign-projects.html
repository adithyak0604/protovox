01 / HOW CAMPAIGNS WORK

From a project brief to a working prototype.

Every campaign should give students a clear route from understanding the problem to demonstrating a working build.

01 / DISCOVERChoose a build

Explore the project objective, difficulty, learning outcomes and expected demonstration.

02 / UNDERSTANDStudy the system

Review the block diagram, core components, circuit plan, code architecture and safety notes.

03 / BUILDUse a RoboBuild kit

Source the matched parts and assemble the prototype through a guided build sequence.

04 / DEMONSTRATETest and present

Validate the build, record observations, debug issues and explain how the system works.
